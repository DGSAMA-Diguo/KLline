> ## 荣耀 / 鸿蒙手机安装提示
>
> 若您是荣耀 MagicOS 6 / 7 / 8 或 HarmonyOS 用户，且仍提示「解析包时出现问题」，
> 请按以下步骤处理（v1.9.5 已内置荣耀专项兼容修复，99% 机型可直接安装）：

1. 卸载手机上已安装的 v1.2.x 旧版（签名变更，必须先卸旧版）
2. 下载 v1.9.5 APK 时**不要用微信/QQ 内置浏览器打开**（它们自带二次校验会误判），
>    请使用手机自带的「浏览器」APP 打开本 README 再点击下载

>    → 设置 → 安全 → 更多安全设置 → 关闭「纯净模式」/ 选择「仍要安装」
> 4. 以上 3 步全部做完仍失败，请重启手机再试一次（部分荣耀机型 PackageManager
>    有 APK 哈希缓存，重启后才会刷新）。

输入一只 A 股代码后，程序会展示最近约 5 年日 K，时间跨度接近五年。
用户可以先在时间轴上选择并放大日期范围，再在主图上拖拽选择 15 至 400 根
历史 K 线，从沪深京 A 股中寻找截至最新交易日、相同根数且所选 K 线、
成交量和 MACD 综合形态最相似的 10 只股票。
双击任意结果，可以在独立窗口中查看该股票最近 150 个交易日的同格式图表，
并通过时间轴拖拽选择日期范围进行缩放。

## 安装

Windows 10 的 PowerShell 中执行：

```powershell
python -m pip install -r requirements.txt
```

## 使用

已经打包好的版本可直接双击：

```text
KLineAgent.exe
```

需要复制到其他电脑时，推荐整体复制完整便携目录：

```text
KLineAgent便携版\
```

便携目录已经包含 Python、第三方依赖和所需动态库，无需在目标电脑部署
本地环境。必须保留目录内的 `_internal` 和 `data` 文件夹，然后双击
`KLineAgent便携版\KLineAgent.exe` 启动。

可执行程序的行情缓存保存在同目录下的 `data\kline_cache.db`，不需要安装
Python。根目录单文件版可以单独移动；便携版必须整体复制，首次查询会自动
重新生成缺失的缓存。

启动图形界面：

```powershell
python gui.py
```

操作步骤：

1. 输入六位 A 股代码，点击"加载 K 线"，查看近三年的历史走势。
2. 点击"更新行情"可立即获取实时全市场行情；程序每五分钟也会自动更新。
3. 在图表底部时间轴上拖拽选择日期范围，主图会同步放大该范围；也可以使用
   "放大图表"和"缩小图表"按钮继续调整。
4. 查看日 K、MA5/10/20/30/60/120、成交量和 MACD，在主图上按住
   鼠标左键拖拽，选择 115 至 400 根连续 K 线。
5. 勾选 K 线、成交量和 MACD 中至少一项，再点击"寻找最新相似走势"。
6. 结果表会同时显示全市场综合相似度最高的 10 只股票及各项分数，无需滚动翻页。
7. 双击结果表中的股票，打开其近 150 日 K 线、均线、成交量和 MACD 图表，
   在弹窗时间轴上拖拽选择日期范围进行缩放。

命令行界面保留原来的最新 20 根日 K 快速查询。直接输入代码：

```powershell
python agent.py 600519
```

也可以输入中文问题：

```powershell
python agent.py "查找和 600519 最近 K 线相似的股票"
```

不带参数运行时，程序会提示输入：

```powershell
python agent.py
```

首次执行片段匹配需要获取全部 A 股最近 120 根日 K，耗时取决于网络状况。
数据保存到 `data/kline_cache.db`；同一交易日再次匹配会直接使用缓存。

## 界面与效率

- 主窗口和股票详情窗口使用统一的浅色卡片界面，结果表可以同时显示全部 10 条结果。
- 图表指标会在行情变化时统一计算并缓存，缩放和时间轴拖拽会直接复用计算结果。
- 主图拖拽选取 K 线时只更新选区覆盖层；全市场查询按区间长度选择更快的缓存读取方式。

## 计算规则

1. K 线使用用户选择片段的开盘、最高、最低和收盘价。
2. 图表显示 MA5、MA10、MA20、MA30、MA60 和 MA120；均线相似度使用
   MA5、MA10 和 MA20，MACD 使用参数 12、26、9。
3. 成交量使用对数标准化，价格和指标按相对形态标准化，以消除股票量级差异。
4. 每只候选股票取截至最新交易日的相同 K 线根数，并使用相同数量的前置
   K 线计算均线和 MACD。
5. 分别计算 K 线、均线、成交量和 MACD 的 0% 至 100% 相似度；综合分只对
   勾选的 K 线、成交量和 MACD 等权平均，均线分保留显示。
6. 排除目标股票以及最新交易日不一致的停牌或过期数据，返回综合分前 10 名。

## 数据接口说明

招商证券没有公开个人开发者 SDK，本项目使用 `pytdx` 读取与招商证券 PC
行情兼容的通达信协议。招商证券旧行情节点不可用时，程序会自动选择其他兼容
只读行情节点。北交所代码和简称从证监会电子化信息披露平台读取，日 K 仍由
通达信兼容行情协议读取。若证监会静态分页短时漏项，程序会用日 K 验证漏掉
的代码，并从东方财富公开行情接口补充其简称。项目不会连接账户，也不包含
委托下单功能。

结果只描述历史行情指标形态，不构成投资建议。
