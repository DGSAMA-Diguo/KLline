# KLine 电脑版（便携版）

## 下载

**直接下载**: [KLineAgent-portable.zip (v1.2.8, 49 MB)](https://github.com/DGSAMA-Diguo/KLline/releases/download/v1.2.8/KLineAgent-portable.zip)

**Gitee 镜像**: [KLineAgent-portable.zip](https://gitee.com/dgsproject/kline/releases/download/v1.2.8/KLineAgent-portable.zip)

## 使用方法

1. 下载 KLineAgent-portable.zip
2. 解压到任意目录
3. 双击运行 KLineAgent.exe

无需安装 Python 环境或任何依赖，解压即用。
